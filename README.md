# EPICS-Lakin-Prep-Project
Collaboration with Lakin Prep Academy in Phoenix to design sensory toys for elementary students.

We designed a Bounce Board and a Build and Balance that were much more durable and built to last for long periods, with easy maintenance in mind. 
Both products were designed with cost-effectiveness in mind and can be manufactured at scale to be affordable for schools and educators.
